# Speech to Text

1. **Подготовка на околината:** Проектот е поделен на два сервиси, `backend` и `frontend`, за да се одделат API логиката и корисничкиот интерфејс.

2. **Креирање на backend:** Изработен е Django REST API со endpoint-и за проверка на здравјето на сервисот и за испраќање аудиоснимки на транскрипција.

3. **Валидација на аудио:** Backend-от проверува дали е испратен фајл и дозволува формати како WAV, MP3, M4A, WebM, OGG, MP4 и FLAC.

4. **Привремено зачувување:** Испратената снимка се запишува во привремен фајл, со што може да се обработува и поголем upload без да се чува трајно во апликацијата.

5. **Интеграција со Whisper:** За претворање на говорот во текст се користи `faster-whisper`, со модел што се вчитува и се кешира во посебен Docker volume.

6. **Поддршка за јазици:** Примарно се дозволени македонскиот и англискиот јазик, а Whisper може автоматски да го препознае јазикот кога е потребно.

7. **Обработка на грешки:** API-то враќа јасни HTTP одговори за невалиден фајл, празна снимка или неуспешна транскрипција, додека привремените фајлови се бришат по обработката.

8. **Креирање на frontend:** Направен е едноставен интерфејс со копче за започнување и прекинување на снимањето, индикатори за состојба и поле во кое се прикажува добиениот текст.

9. **Снимање од прелистувач:** Frontend-от го користи `MediaRecorder` API за снимање од микрофонот и аудиото го испраќа како `recording.webm`.

10. **Поврзување на сервисите:** Nginx го сервира frontend-от и ги проследува барањата од `/api/` кон Django backend-от, па корисникот пристапува преку една адреса.

11. **Docker конфигурација:** Backend-от се извршува со Python 3.11, FFmpeg и Gunicorn, додека frontend-от се извршува со Nginx Alpine image.

12. **Оркестрација:** `docker-compose.yml` го стартува backend-от пред frontend-от, користи healthcheck за проверка на API-то и овозможува долги timeout периоди за транскрипција.

## Стартување

1. Во коренот на проектот креирајте `.env` фајл. Доволни се следните вредности, а портите може да се променат ако се зафатени:

   env:
   BACKEND_PORT=8000
   FRONTEND_PORT=8080
   

2. Стартувајте ги сервисите со:

   docker compose up --build
  

3. Отворете `http://localhost:8080` во прелистувач со дозволен пристап до микрофонот.

4. Притиснете **Start Listening**, зборувајте, а потоа притиснете **Stop Listening**. По завршувањето на обработката, транскрипцијата ќе се појави во текстуалното поле.

5. За проверка на backend health endpoint-от отворете `http://localhost:8000/api/health/` или користете `http://localhost:8080/api/health/` преку Nginx proxy.

Кога корисникот ќе започне снимање, прелистувачот го зема звукот од микрофонот и го собира во WebM аудиоблоб. По прекинот, blob-от се испраќа до `/api/transcribe/`, Django го зачувува привремено и го предава на `faster-whisper`, кој го враќа препознаениот текст како JSON одговор; frontend-от потоа го прикажува текстот во полето за транскрипција.
